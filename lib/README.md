# Dependência local

O projeto utiliza somente `gson-2.14.0.jar`, mantido da versão original, para serialização JSON. Sua licença Apache 2.0 está em `GSON-LICENSE.txt`. Coordenadas Maven: `com.google.code.gson:gson:2.14.0`.

Swing, sockets, leitura/gravação de arquivos e travas usam o Java padrão. Não há driver de banco de dados nem downloads durante a compilação.
