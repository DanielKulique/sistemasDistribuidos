# Dependências locais

Gson 2.14.0 foi mantido do projeto original; licença em GSON-LICENSE.txt.

Driver oficial MongoDB 5.2.1: mongodb-driver-sync, mongodb-driver-core e bson. Artefatos baixados de https://repo.maven.apache.org/maven2/org/mongodb/, com SHA-1 conferido contra os checksums publicados. Licença Apache 2.0 em MONGODB-LICENSE.txt, obtida do repositório oficial mongo-java-driver, tag r5.2.1.

Coordenadas Maven: org.mongodb:mongodb-driver-sync:5.2.1; core e BSON são dependências transitivas. A compilação não faz downloads.
